# HTML 프레젠테이션 스튜디오

브라우저만으로 동작하는 파워포인트형 프레젠테이션 편집기 + 발표 프로그램입니다.
설치·빌드가 필요 없고, **Claude 스킬로 슬라이드를 만들고 실시간으로 제어**할 수 있습니다. (기획: `PLAN.md`)

## 실행
- **권장:** `start.bat` 더블클릭 → `http://localhost:8080` 으로 열림
  - Node.js 가 있으면 **실시간 연동 서버**(`server.js`)로 실행 → 상단에 `🔗 Claude 연동` 표시
  - 없으면 Python 단순 서버로 실행 (Claude 실시간 연동 없음)
- `index.html` 을 Chrome/Edge 로 직접 열어도 편집·발표는 됩니다 (YouTube·녹화·연동은 서버 실행 권장).

## Claude 스킬로 슬라이드 제어 (`slide-studio`)
이 폴더에서 Claude Code 를 실행하면 `.claude/skills/slide-studio` 스킬을 사용할 수 있습니다.

- 예: *"신제품 런칭 피치덱 10장을 네이비 골드 팔레트로 만들어 줘"*, *"3번 슬라이드를 차트로 바꾸고 퀴즈 하나 추가해 줘"*, *"카드뉴스 4:5 로 만들어서 발표 시작해 줘"*
- Claude 가 하는 일: 서버 실행 → 디자인 포맷/팔레트/레이아웃 선택 → 덱 생성 → **PNG 로 렌더링해 직접 검토·수정** → 편집기에 실시간 반영 → 발표 시작/이동/내보내기
- 편집기에서 직접 고친 내용도 Claude 가 다시 읽어서 이어서 작업합니다 (양방향).
- 직접 써 볼 수도 있습니다:
  ```
  node .claude/skills/slide-studio/scripts/deck.mjs help
  node .claude/skills/slide-studio/scripts/deck.mjs start --open
  node .claude/skills/slide-studio/scripts/deck.mjs build .claude/skills/slide-studio/examples/pitch-deck.json
  node .claude/skills/slide-studio/scripts/deck.mjs present 1
  ```
- 디자인 가이드(포맷 10종·팔레트 18종·글꼴 조합): `.claude/skills/slide-studio/reference/design.md`
- 사양·수정 연산 레퍼런스: `.claude/skills/slide-studio/reference/spec.md`
- 실시간 덱 파일: `decks/live.hppt.json` (서버가 처음 만들 때 편집기의 현재 문서를 올립니다)

## 파일 구조
```
index.html        편집기 화면
server.js         로컬 서버 + 실시간 덱 공유 API (외부 패키지 없음)
css/app.css       편집기 스타일
js/core.js        렌더러 · 애니메이션 · 전환 · 차트 · 배경 효과 · 발표 플레이어 (HTML 내보내기에 그대로 포함)
js/store.js       문서 모델 · 테마 · 레이아웃 · 화면 비율 · 실행 취소 · 자동 저장
js/editor.js      캔버스 편집
js/panels.js      슬라이드 목록 · 속성 · 애니메이션 · 슬라이드 패널
js/io.js          저장/열기 · HTML/PDF 내보내기
js/live.js        편집기 ↔ 서버 실시간 동기화 · 원격 명령
js/app.js         초기화 · 툴바 · 단축키 · 클립보드
.claude/skills/slide-studio/   Claude 스킬 (SKILL.md, CLI, 레퍼런스, 예제)
```

F1 을 누르면 단축키 전체 목록이 표시됩니다.
